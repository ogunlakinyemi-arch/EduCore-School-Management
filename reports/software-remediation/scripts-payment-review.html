Genuine Flutterwave TEST read — separate from mocked tests

The dedicated Development TEST credential passed local TEST-only validation and performed GET /v3/banks/NG. The provider returned HTTP 200 with 598 catalog entries. A separate GET to the same endpoint without an Authorization header returned HTTP 401. No credentials, bank details or upstream response bodies were printed or saved.

This establishes TEST authentication only. It does not establish a successful checkout, paid transaction, delivered webhook, persistent invoice credit, receipt, subscription activation, bank payout or actual split settlement. Both requests were read-only and had zero provider mutations and zero application database access.
