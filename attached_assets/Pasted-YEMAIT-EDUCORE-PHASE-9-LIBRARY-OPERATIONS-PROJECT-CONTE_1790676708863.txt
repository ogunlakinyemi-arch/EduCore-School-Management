2. LIBRARY ROLES

SCHOOL ADMIN

School Admin controls the school's Library and Operations.

Can:

- Add/edit library books
- Manage book copies
- Manage categories
- Manage authors/publishers
- Register library items
- Issue books
- Receive returns
- Manage overdue items
- Manage lost/damaged items
- Manage authorized library staff
- View reports
- Manage operational records

All actions remain restricted to their school.

TEACHER

Teacher may:

- Search available library resources
- Borrow books if enabled
- View own borrowing history
- Return/renew authorized books

Teacher must not manage the entire library unless explicitly assigned an appropriate library-management permission.

STUDENT

Student may:

- Search available books
- View book details
- See availability
- View own borrowed books
- See due dates
- Request/borrow where the school's workflow permits
- View own borrowing history

Student must not access another student's library records.

PARENT

Parent may:

- View library activity of linked children where enabled
- See books currently borrowed by their children
- See due dates
- See overdue status

Parent must not access unrelated students' records.

ACCOUNTANT

Accountant should only see library financial information if the existing school finance authorization permits it.

Do not give Accountant unrestricted library-management access.

PARTNER

Partner has no ordinary school library-management access.

PLATFORM OWNER

Platform Owner may retain platform-level visibility where already authorized, but must not automatically receive school operational write permissions.

Do not use Platform Owner status as a shortcut to school-level library or operations management.

- COPY-001
- COPY-002
- COPY-003

Each physical copy should support:

- Unique copy identifier
- Book reference
- School
- Condition
- Status
- Location
- Acquisition information where applicable

Possible copy statuses:

- AVAILABLE
- BORROWED
- RESERVED
- LOST
- DAMAGED
- MAINTENANCE
- RETIRED

Do not allow two active physical copies in the same school to have the same unique identifier.
