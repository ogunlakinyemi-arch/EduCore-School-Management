4. DATA-SAFETY CLASSIFICATION

Every failed or concerning preflight must be classified as:

GREEN

No issue. Migration can proceed for this object.

YELLOW

Needs review but does not necessarily block the entire migration.

RED

Applying the migration could:

- fail
- alter existing semantics unexpectedly
- invalidate existing data
- cause data loss
- break tenant ownership
- break Finance integrity
- require destructive remediation

Any RED result blocks Production migration.
