1. AUTHENTICATED BROWSER VERIFICATION

The previous browser verification only reached the Clerk sign-in screen.

Use the existing development environment to perform authenticated browser verification.

Use an authorized test account/session.

Verify the actual attendance pages after authentication.

At minimum verify:

Platform Owner

- Can access authorized device management
- Can view attendance-related platform information where permitted
- Cannot bypass authorization through manipulated IDs

School Admin

- Can access their school's attendance dashboard
- Can view attendance events
- Can view discrepancies
- Can use permitted manual attendance functions
- Can view authorized devices
- Cannot access another school's attendance data

Teacher

Verify the actual permissions implemented by the application.

Teacher must only access attendance information permitted by their school/class scope.

Parent

Verify:

- Parent can see only their linked child/children
- Parent cannot modify attendance
- Parent cannot access unrelated students

Student

Verify the implemented student attendance access.

Student must only see their own authorized information.

Partner

Verify that Partner access remains restricted to the partner ecosystem and does not expose school attendance operations.

CLASSROOM attendance recorded.
