ADDITIONAL ISSUE — PARENT CHILD TIMETABLE AND CLASS TEACHER

The Parent dashboard currently has two related problems:

1. Parent cannot view the child's timetable
   
   - Parent → Child → Timetable displays:
     "HTTP 404 Not Found: Student not found"
   - A Retry button is shown, but retrying does not resolve the issue.
   - The timetable must load using the selected/linked child from the authenticated Parent account.
   - Do not require the Parent to manually enter a Student ID.
   - Do not use the Parent's own user ID as the Student ID.
   - Do not use admission number where the API expects the internal student ID.

2. Parent cannot view the child's Class Teacher
   
   - Parent dashboard should display the child's current Class Teacher.
   - The Class Teacher must be resolved from the child's current school, academic session, class and section.
   - Only the teacher assigned to that child's current class/section should be displayed.
   - Do not expose teachers from another school, class, section or historical enrollment.
