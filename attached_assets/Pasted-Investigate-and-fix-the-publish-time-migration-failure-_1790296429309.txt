PostgreSQL error:

ROOT CAUSE TO INVESTIGATE

The migration creates a composite foreign key:

nfc_card_history(nfc_card_id, school_id)
->
nfc_cards(id, school_id)

PostgreSQL requires the referenced columns on nfc_cards to be covered by a PRIMARY KEY or UNIQUE constraint/index.

The generated migration appears to create many tenant-scoped composite constraints such as UNIQUE(id, school_id), but the shown migration does not add an equivalent composite uniqueness constraint to nfc_cards.

Do not assume this is the only schema issue. Inspect the actual schema definitions and migration generator/source schema first.
