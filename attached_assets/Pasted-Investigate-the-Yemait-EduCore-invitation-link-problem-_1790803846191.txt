Investigate the Yemait EduCore invitation-link problem using READ-ONLY inspection first.

PROBLEM:

When a newly invited user opens an invitation link:

1. The invitation link opens.
2. It shows "Loading session..." or a similar session-loading state.
3. Instead of opening the intended password/setup page for the invited user, it redirects to the Replit login page.

EXPECTED BEHAVIOR:

Invitation link
→ invitation/session validation
→ EduCore password/setup page
→ user creates password
→ account setup completes
→ user is redirected to the appropriate EduCore dashboard.

IMPORTANT:

- Do NOT modify application code yet.
- Do NOT change Clerk configuration.
- Do NOT change Replit authentication settings.
- Do NOT revoke or recreate invitations.
- Do NOT modify database data.
- Do NOT change secrets.
- Do NOT republish or restart the deployment.
- READ-ONLY investigation only.
