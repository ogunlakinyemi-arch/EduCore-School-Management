---
name: Academic periods in Owner fee oversight
description: Product intent for school-owned academic-term selection in cross-school financial oversight.
---

The Owner's NFC Fee Collection Oversight must use the schools' existing
academic periods, not a separate financial calendar or terms created to
populate a filter. Owners must not have to look up and type numeric school or
academic-term identifiers.

**Why:** Schools already create their terms in EduCore. Cross-school oversight
must respect those records, and repeated term names do not identify a shared
period across schools or sessions.

**How to apply:** Preserve historical choices and clear school/session context.
Default only to an unambiguous current active period within the selected scope;
ambiguity requires an explicit choice, never selecting the first matching name.
Filter improvements do not authorize changes to academic records, fee status,
payment safeguards, Production configuration or LIVE provider activity.
