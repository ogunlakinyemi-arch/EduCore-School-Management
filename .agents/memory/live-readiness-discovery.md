---
name: LIVE readiness discovery
description: Where Owners expect to find the separate LIVE evidence preview and why navigation must not imply activation.
---

Owners expect to find LIVE readiness from the existing Financials / Flutterwave
Splits / Split Settlements workflow, not solely from Partner administration.
Keep it discoverable on mobile rather than relying only on horizontal tabs.

**Why:** The user repeatedly could not find the preview while navigating the
existing financial screen and explicitly requested access from there.

**How to apply:** Preserve an explicit, Owner-authorized Development entry from
the financial workflow. Describe it as a separate read-only evidence preview,
never as a collection-mode switch or an approval/activation action.
