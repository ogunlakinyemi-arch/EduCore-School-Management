Teacher period notifications are Development-only: five minutes before the scheduled start and at the scheduled end, for the teacher selected on the timetable with a valid subject-teacher or class-teacher assignment. Dual assignments must not duplicate notifications.

**Why:** The user requested a small, low-credit change, initially chose In-app and push only, and subsequently explicitly approved the minimum Development-only schema and linking prerequisite for teacher Telegram.

**How to apply:** Teacher Telegram is now within the approved Development scope: authenticated teacher-owned linking, private chat verification, separate explicit confirmation/consent, withdrawal and chat uniqueness across accounts. Preserve parent linking and consent independently, including dual-role accounts. Reuse school timezone, queues, Owner selections, audit and deduplication; revalidate queued push/Telegram against timetable changes and expiry. Do not enable channels, select recipients, unpause workers, bypass payment-test safeguards or perform real test sends. Only the minimum prerequisite schema was authorized for verified Development; no Production migration, publishing or real delivery verification was authorized.
