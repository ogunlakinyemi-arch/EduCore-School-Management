---
name: Same-day class history
description: Why reporting on attendance must consider assignment creation time as well as calendar dates.
---

When reconstructing a student's class at an attendance event, a date-range match alone is insufficient if a class changes during that calendar day. The assignment must already have existed when the event occurred.

**Why:** An old assignment's end date and a new assignment's start date can both cover the same day. Choosing the newest date-matching assignment can expose an earlier gate event to the new class's teacher and hide it from the previous teacher.

**How to apply:** For reports that reconstruct historical class scope from assignments rather than event snapshots, compare the assignment's creation instant with the event instant, and keep the event's original school boundary. Test same-day changes explicitly.
